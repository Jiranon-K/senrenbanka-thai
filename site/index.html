How to install

วิธีติดตั้งแพตช์ภาษาไทย 3 ขั้น

ไม่ต้องแก้ไฟล์ .exe ไม่ต้องใช้ตัวโหลดพิเศษ ตัวติดตั้งหาโฟลเดอร์เกมให้เอง

  1. 1

    ดาวน์โหลดแล้วแตกไฟล์

    โหลด senrenbanka-thai-patch-v1.3.1.zip จาก หน้า Releases แล้วแตกไฟล์ไว้ที่ไหนก็ได้ — ไม่ต้องแตกทับโฟลเดอร์เกม

  2. 2

    เปิดตัวติดตั้ง

    ดับเบิลคลิก SenrenBanka-Thai-Patch.exe แล้วกด “ถัดไป” ตัวติดตั้งจะหาโฟลเดอร์เกมให้

  3. 3

    ตั้งภาษาในเกม

    เปิดเกม → Config → Language → เลือก Chinese (Simplified) แล้วเกมจะแสดงเป็นภาษาไทยทันที

    ไม่อยากใช้ตัวติดตั้ง? ในซิปมี install.bat / uninstall.bat ให้ด้วย

FAQ

คำถามที่พบบ่อย

ทำไมต้องตั้งภาษาเกมเป็นจีน (Chinese Simplified)?

เกมเก็บบทพูดแต่ละบรรทัดไว้เป็นช่องภาษา (ญี่ปุ่น / อังกฤษ / จีน / จีนไต้หวัน) แพตช์นี้ใส่คำแปลไทยลงในช่องจีน และสลับฟอนต์จีนเป็นฟอนต์ไทย จึงไม่ต้องแก้ตัวเกม เมื่อ Steam อัปเดตก็แค่ลงแพตช์ใหม่

ลงแพตช์ R18 ไว้แล้ว ใช้ได้ไหม?

ได้ ซิปเดียวใช้ได้ทั้งสองแบบ ตัวติดตั้งตรวจเองว่าลงแพตช์ R18 ไว้หรือไม่ ลำดับที่ถูกต้องคือ เกม → แพตช์ R18 → แพตช์ไทย

ห้ามรันตัวติดตั้งแพตช์ R18 ซ้ำหลังลงไทยแล้ว เพราะจะเขียนทับไฟล์จนภาษาไทยหายทั้งเกม ถ้าเผลอไปแล้ว ให้ถอดแพตช์ไทย → ลง R18 → ลงไทยใหม่

ถอดแพตช์ออกยังไง?

เปิดตัวติดตั้งแล้วกด “ถอดแพตช์” หรือดับเบิลคลิก uninstall.bat ไฟล์ต้นฉบับถูกสำรองเป็น .bak ไว้ก่อนแปะทับเสมอ จึงไม่ต้องโหลดเกมใหม่

ปลอดภัยไหม? ทำอะไรกับเครื่องบ้าง?
  • ไม่แตะอะไรนอกโฟลเดอร์เกม ไม่เขียน registry ไม่ต่อเน็ต
  • ตรวจ SHA256 ก่อนแตะไฟล์ ถ้าเวอร์ชันเกมไม่ตรงจะแจ้งตั้งแต่ต้น
  • สำรองไฟล์ก่อนเสมอ และคืนไฟล์เดิมให้อัตโนมัติถ้าเกิดพลาดกลางคัน
  • ในซิปไม่มีเนื้อหาเกม มีเพียง binary diff (xdelta) และโค้ดทั้งหมดเปิดอยู่บน GitHub
ลงแล้วยังเป็นภาษาจีนหรือภาษาอังกฤษอยู่
  1. ตรวจว่าตั้ง Language = Chinese (Simplified) ในหน้า Config แล้ว
  2. ถ้าตั้งแล้วยังเป็นจีน แปลว่ามีแพตช์ R18 ทับอยู่ — รัน uninstall.bat แล้วลงใหม่
  3. ถ้าเป็นแค่บางบรรทัด คือบทพูดฉาก H ในแพตช์ R18 ที่ยังแปลไม่ถึง
ต้องมีเกมแท้ไหม?

ต้องมี แพตช์นี้เป็น binary diff ถ้าไม่มีไฟล์เกมแท้ในเครื่องจะใช้งานไม่ได้ เกมมีขายบน Steam
