How to install

ไม่ต้องแก้ไฟล์ .exe ไม่ต้องใช้ตัวโหลดพิเศษ ตัวติดตั้งหาโฟลเดอร์เกมให้เอง

  1. 1

    ดาวน์โหลดแล้วแตกไฟล์

    Download

    โหลดไฟล์ zip จากหน้า Releases แล้วแตกไว้ที่ไหนก็ได้ ไม่ต้องแตกทับโฟลเดอร์เกม

    ZIP

    senrenbanka-thai-patch-v1.3.1.zip

    57 MB · อัปเดต 31 ต.ค. 2026

    ดาวน์โหลด
    • มี SenrenBanka-Thai-Patch.exe และ install.bat / uninstall.bat สำหรับคนที่ไม่อยากใช้ตัวติดตั้ง
    • ไม่มีไฟล์เกม มีแต่ส่วนต่าง (xdelta) ที่ใช้ได้กับเกมแท้เท่านั้น
    • ตรวจเวอร์ชันเกมด้วย SHA256 และสำรองไฟล์เดิมเป็น .bak ก่อนแปะทุกครั้ง
  2. 2

    เปิดตัวติดตั้ง

    Run the installer

    ดับเบิลคลิก SenrenBanka-Thai-Patch.exe แล้วกด “ถัดไป” จนจบ ตัวติดตั้งหาโฟลเดอร์เกมใน Steam ให้เอง

  3. 3

    เลือกภาษาไทยในเกม

    System config · Language

    เปิดเกม ไปที่ Config → Language แล้วเลือก ภาษาไทย เมนูและบทพูดจะเปลี่ยนเป็นภาษาไทยทันที

!

【 ใช้แพตช์ R18 ด้วย? 】

Frequently asked
ทำไมตัวเลือก “ภาษาไทย” อยู่ในช่องของภาษาจีน?

เกมเก็บบทพูดแต่ละบรรทัดเป็นช่องภาษาเรียงกัน (ญี่ปุ่น / อังกฤษ / จีน / จีนไต้หวัน) แพตช์นี้ใส่คำแปลไทยลงในช่องจีน (Simplified) เปลี่ยนชื่อช่องเป็น “ภาษาไทย” และสลับฟอนต์เป็นฟอนต์ไทย

ข้อดีคือไม่ต้องแก้ตัวเกม ไม่ยุ่งกับ .exe และเมื่อ Steam อัปเดตก็แค่ลงแพตช์ใหม่

ลงแพตช์ R18 ไว้แล้ว ใช้ได้ไหม?

ได้ ซิปเดียวใช้ได้ทั้งสองแบบ ตัวติดตั้งตรวจเองว่าลงแพตช์ R18 ไว้หรือไม่ ลำดับที่ถูกต้องคือ เกม → แพตช์ R18 → แพตช์ไทย

ถ้าเผลอรันตัวติดตั้ง R18 ซ้ำหลังลงไทย ให้ถอดแพตช์ไทย → ลง R18 → ลงไทยใหม่

ถอดแพตช์ออกยังไง?

เปิดตัวติดตั้งแล้วกด “ถอดแพตช์” หรือดับเบิลคลิก uninstall.bat ไฟล์ต้นฉบับถูกสำรองเป็น .bak ไว้ก่อนแปะทับเสมอ จึงไม่ต้องโหลดเกมใหม่

อัปเดตจากเวอร์ชันเก่าต้องทำยังไง?

กด “ถอดแพตช์” ก่อน แล้วค่อยลงเวอร์ชันใหม่

ปลอดภัยไหม? ทำอะไรกับเครื่องบ้าง?
  • ไม่แตะอะไรนอกโฟลเดอร์เกม ไม่เขียน registry ไม่ต่อเน็ต
  • ตรวจ SHA256 ก่อนแตะไฟล์ ถ้าเวอร์ชันเกมไม่ตรงจะแจ้งตั้งแต่ต้น
  • สำรองไฟล์ก่อนเสมอ และคืนไฟล์เดิมให้อัตโนมัติถ้าเกิดพลาดกลางคัน
  • โค้ดทั้งหมดเปิดอยู่บน GitHub ตรวจได้ทุกบรรทัด
ลงแล้วยังเป็นภาษาจีนหรือภาษาอังกฤษอยู่
  1. ตรวจว่าเลือก ภาษาไทย ใน Config → Language แล้ว
  2. ถ้าทั้งเกมยังเป็นจีน แปลว่ามีแพตช์ R18 ทับอยู่ ให้รัน uninstall.bat แล้วลงใหม่
  3. ถ้าเป็นแค่บางบรรทัด คือบทพูดฉาก H ในแพตช์ R18 ที่ยังแปลไม่ถึง
Windows ขึ้นเตือน “Windows protected your PC”

ตัวติดตั้งไม่ได้เซ็นชื่อดิจิทัล Windows SmartScreen จึงเตือนกับโปรแกรมใหม่ที่ยังมีคนโหลดไม่มาก ไม่ได้แปลว่าเจอไวรัส กด More info แล้วกด Run anyway ได้เลย

ถ้าไม่สบายใจ เช็กค่า SHA256 ของไฟล์ zip กับหน้า Releases หรือใช้ install.bat ในซิปแทน ผลลัพธ์เหมือนกันและเปิดอ่านได้ทุกบรรทัด

ต้องมีเกมแท้ไหม?

ต้องมี แพตช์เป็นไฟล์ส่วนต่าง (binary diff) ถ้าไม่มีไฟล์เกมแท้ในเครื่องจะใช้งานไม่ได้ เกมมีขายบน Steam

ยังติดปัญหา? เปิด Issue บน GitHub พร้อมภาพหน้าจอ แล้วจะตามแก้ให้
