แหล่งอ้างอิง

Patterns, not code

แนวคิดมาจากหน้า component ที่คนอื่นออกแบบไว้ แต่โค้ดทุกบรรทัดเขียนใหม่ในสแตกของเรา (HTML/CSS/JS ล้วน) ไม่ได้คัดลอกซอร์สหรือ asset หน้าที่อ่านไม่ได้ระบุสัญญาอนุญาตของ component จึงใช้เฉพาะแนวคิดเชิงพฤติกรรม

ของเราแนวคิดที่ยืมต้นทาง
.beam บนปุ่มดาวน์โหลดแสงวิ่งรอบกรอบ ใช้กับ CTA เดียวเพื่อดึงสายตาMagic UI · Border Beam, Shimmer Button
ตัวเลข % นับขึ้นบนมาตรวัดนับจากศูนย์เมื่อเลื่อนมาถึง ครั้งเดียว ชะลอตอนท้ายMagic UI · Number Ticker, Animata · Counter
เส้น beam และขั้นที่ผ่านแล้วในขั้นตอนติดตั้งเส้นเติมตามการเลื่อน จุดหมายขั้นสว่างขึ้นเมื่อถึงAnimata · Animated Timeline, Aceternity · Timeline
.seg และตัวชี้ใน navแถบเลื่อนอันเดียวย้ายไปหาตัวที่เลือกcoss ui · Segmented Control (ปลายทางของ originui.com)
[data-spot]แสงและขอบเรืองตามตำแหน่งเมาส์React Bits · Spotlight Card, Animata · Glowing Card
reveal ตอนเลื่อนเลื่อนขึ้นเล็กน้อยพร้อมจาง เป็นลำดับAnimata · Scroll Reveal (ใช้เฉพาะแนวคิดลำดับ)

อ่านแล้วไม่นำมาใช้: Aceternity Sticky Scroll Reveal (ซ้อนเนื้อหาไว้ตามตำแหน่งเลื่อน ทำให้ข้ามอ่านยาก) และ Motion Primitives (ตอนค้นคว้าเซิร์ฟเวอร์ตอบ 403 จึงไม่ได้อ้างอิงอะไรจากที่นั่น) ดูรายละเอียดและการตรวจสอบใน docs/design/site-design-system.md
