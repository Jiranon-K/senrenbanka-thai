## 1. Misaligned lines (biggest issue)

Heuristic: the JP line opens with a quote bracket (`「『（`) but the Thai does not, or vice versa.
1,744 of 45,120 translated R18 lines fail it. A sliding 60-line window that searches offsets −40..+40
splits them into two kinds:

**Shifted by a constant offset — fixable by re-indexing the existing Thai**

| file | where | offset |
|---|---|---|
| 003 | from ~idx 240 to end | −1 |
| 106 | ~420–540 | +3 |
| 107 | ~60–300, ~420–700 | +2/+3, −1/−3 |
| 108 | ~240–420 | +2 |

**No consistent offset — Thai does not match JP, needs retranslation**

| file | where | bad lines |
|---|---|---|
| 001 | whole file | 565 / 782 |
| 414 | ~300–420 | 86 |
| 417 | ~240–420, ~660–end | 207 |
| 418 | scattered | 39 |
| 420 | ~360–480 | 81 |
| 421 | scattered | 31 |
| 424 | scattered | 44 |
| 503 | ~300–end | 121 |
| 416 | scattered | 22 |

Example: 001 idx 312, JP `「本当に久しぶりだな！…」` (Rentarou greeting) → Thai `ไอ้โง่ออออ!`.
Some of the "profanity" seen in play comes from these lines, not from word choice.

## 2. Profanity / register

|---|---|---|---|

Rentarou's pronouns also drift by chapter (ข้า/แก, ฉัน/นาย, ผม, กู/มึง). Needs one standard in `glossary.csv`.

Candidate list (426 lines incl. milder ไอ้/แก/ว่ะ) was produced by a regex scan; most ไอ้/แก hits are fine
(e.g. cursed spirit `人間め` → `ไอ้มนุษย์`).
